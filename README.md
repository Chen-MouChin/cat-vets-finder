# 全台動物醫院查詢（單檔版）

全台 22 縣市 2,001 家動物醫院，政府公開登記資料。可搜尋、選縣市、只看 24 小時急診或貓專科，手機定位列出最近的幾家，一鍵打電話或導航。

- 線上版：https://chen-mouchin.github.io/cat-vets-finder/
- 原始碼：https://github.com/Chen-MouChin/cat-vets-finder
- 規格書：[SPEC.md](SPEC.md)
- 完整網站：貓健康站 https://chen-mouchin.github.io/cat-health-tw/ （這一頁是站上的獸醫院查詢頁）

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 交付物。CSS、JavaScript、2,001 筆資料全部內嵌，約 380 KB，離線可用 |
| `build_single.py` | 從貓健康站的 `frontend/vets.html` 產生 `index.html`：內嵌樣式與資料、拿掉廣告位、站內連結改絕對網址。程式邏輯和線上版同一份 |
| `SPEC.md` | 規格書：資料、功能、驗收條件、修改紀錄 |

## 怎麼用

1. 打開頁面，直接捲動或在搜尋框打院名、地址、區名。
2. 點縣市按鈕只看一個縣市；「只看 24h 急診」「只看貓專科」可以同時開。
3. 手機按「找我附近的獸醫院」，允許定位後列出最近的 10 家，可切換 1 到 20 km 範圍。
4. 每家卡片的電話可直接撥，「導航」開 Google 地圖路線。

定位需要 HTTPS，GitHub Pages 的網址符合；自己電腦開檔案要用 `localhost` 起一個 server。

## 開發過程（與 AI 反覆修改的紀錄）

工具：Claude Code。作者負責想法、資料來源、驗收與決策；AI 負責整理規格、寫程式、爬資料、自我檢查。

這一頁是貓健康站從 2026 年 4 月做到現在的一部分，細節在站上的 `docs/PROGRESS.md`。幾個關鍵決定：

1. **資料用政府名冊，不爬 Google**。Google 地圖的結果混進寵物店與歇業店，農業部名冊是登記制，乾淨；缺的座標用 OpenStreetMap 補，缺的地址用農業部 API 補。
2. **導航交給 Google 地圖**。原本想接路線 API 顯示車程，討論後決定站內只算直線距離，導航時把文字地址交給 Google，省掉付費 API，也不用把使用者位置送出去。
3. **定位要有退路**。手機 GPS 在室內常抓不到，所以先試 GPS、逾時退回網路定位；拒絕定位時給 iPhone 與 Android 的設定路徑；LINE 內建瀏覽器無法定位，偵測到就提醒換瀏覽器。
4. **篩選要誠實**。24h 與貓專科是靠名字加人工名單判斷，會漏，所以開篩選時畫面直接說明，並提醒先打電話確認。
5. **交付物換題**。作業原本想做「貓咪急診判斷器」，做完第一版後作者認為工具不該替飼主判斷要不要就醫，那是獸醫的事，改以這一頁為交付物，用 `build_single.py` 打包成單檔。
